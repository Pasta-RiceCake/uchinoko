# うちの子手帳

うちの子手帳は、妊娠中から子育て中まで使える無料の子育て手帳です。予定、手続き、家事、買い物などをパートナーと共有できます。共有にはリンクと「あいことば」を使うので、ログインはいりません。

## しくみ

Cloudflare Workers と D1 で動きます。どちらも無料プランの範囲で足ります。

- `public/`：画面です。このうち `index.html` は `tools/real.py` で作ります。
- `src/worker.js`：共有データを D1 に保存する API（`/api/fam`）です。
- D1 のテーブルは、最初にアクセスがあったときに自動で作られます。

## 画面を作り直すとき

```
python3 tools/real.py
```

`tools/proto.html`（見本）を元にして、本番用の変更を足した `public/index.html` を書き出します。本番用の変更は、データの保存と共有、はじめての画面です。

## 公開

1. Cloudflare の「Workers & Pages」を開きます。
2. 「作成」から「Gitリポジトリをインポート」を選びます。
3. このリポジトリを選びます。

これで、`main` に push するたびに自動で公開されます。D1 データベースは、公開のときに自動で作られます。
